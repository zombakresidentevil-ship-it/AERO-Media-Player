# AERO Media Player

Русскоязычный аудио- и видеоплеер для Windows. Проект использует PySide6 для интерфейса и VLC/libVLC для воспроизведения медиа.

## Возможности

- Воспроизведение широкого набора аудио- и видеоформатов через VLC.
- Плейлисты M3U, M3U8, PLS, XSPF, ASX, WPL, B4S и SMIL.
- Очередь воспроизведения, поиск, перемешивание и повтор.
- 10-полосный эквалайзер.
- Обложки и чтение тегов музыкальных файлов.
- Поддержка сетевых потоков.

Фактическая поддержка кодеков зависит от версии VLC и конкретного медиафайла.

## Сборка Windows через GitHub Actions

Workflow уже добавлен в `.github/workflows/build-windows.yml`.

1. Скачайте ZIP с исходным проектом из сообщения ChatGPT.
2. В этом репозитории нажмите **Add file → Upload files**.
3. Загрузите файл с точным именем `AERO_Media_Player_Project.zip` в корень репозитория и нажмите **Commit changes**.
4. Откройте вкладку **Actions** и выберите **Build Windows x64**.
5. После успешного завершения откройте запуск workflow и скачайте artifact **AERO-Media-Player-Windows-x64**.

Workflow устанавливает Python и VLC, ставит зависимости, запускает тесты плейлистов, собирает переносимую папку приложения и публикует ZIP как artifact на 14 дней.

Также сборку можно запустить вручную через **Actions → Build Windows x64 → Run workflow** после загрузки исходного ZIP.

## Локальный запуск

Требуются Python 3.10+ и установленный VLC x64.

- Запустите `run_dev.bat` для разработки.
- Запустите `build_win.bat` для локальной сборки.

## Примечание

Это ранняя версия проекта. До распространения готового EXE нужно проверить воспроизведение на реальной Windows-системе, в том числе с разными кодеками и аудиоустройствами.
