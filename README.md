# AERO Media Player

Русскоязычный аудио- и видеоплеер для Windows. Проект использует PySide6 для интерфейса и VLC/libVLC для воспроизведения медиа.

## Возможности

- Воспроизведение широкого набора аудио- и видеоформатов через VLC.
- Плейлисты M3U, M3U8, PLS, XSPF, ASX, WPL, B4S и SMIL.
- Очередь воспроизведения, поиск, перемешивание и повтор.
- 10-полосный эквалайзер.
- Обложки и чтение тегов музыкальных файлов.
- Поддержка сетевых потоков.

Фактическая поддержка кодеков зависит от версии VLC и конкретного медиафайла.

## Сборка Windows через GitHub Actions

Исходный архив хранится в репозитории частями в каталоге `.source`. Workflow самостоятельно собирает ZIP, проверяет его SHA-256, устанавливает VLC и зависимости, запускает тесты плейлистов и собирает переносимую Windows x64-версию.

1. Откройте вкладку **Actions**.
2. Выберите **Build Windows x64**.
3. После успешного выполнения откройте запуск и скачайте artifact **AERO-Media-Player-Windows-x64**.

Сборка запускается автоматически при обновлении исходных частей или workflow. Повторный запуск доступен через **Actions → Build Windows x64 → Run workflow**.

## Локальный запуск

Требуются Python 3.10+ и установленный VLC x64.

- Запустите `run_dev.bat` для разработки.
- Запустите `build_win.bat` для локальной сборки.

## Примечание

Это ранняя версия проекта. Готовую сборку необходимо проверить на реальной Windows-системе, включая различные кодеки и аудиоустройства.
